# v1.5.1 release

Fix pre-push verification from Git worktrees: temporary checkouts now clear repository-local Git environment variables, and all Git calls during candidate verification use that isolated environment. The source worktree's HEAD, index, and files remain unchanged, including when pushing a commit other than its current HEAD.

A regression test performs real worktree pushes to a local bare repository with an isolated home, covering Git's native Hook environment and explicit worktree, common-directory, and index variables.

Repository configuration schema, pre-push protocol, and execution-contract versions are unchanged. Existing repositories must explicitly install the verified v1.5.1 release and update their locked engine identity to receive the fix.
