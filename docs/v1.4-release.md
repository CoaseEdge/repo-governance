# v1.4 release

Version 1.4 adds deterministic architecture governance and Change Scope Governance without changing repository configuration schema version 1, pre-push protocol version 1, or execution-contract version 1.

RG007 introduces optional architecture contracts, static JavaScript, TypeScript, and Python dependency graphs, architecture baselines, deterministic drift metrics, and health scoring. RG008 introduces optional Task Contracts, path and change-budget enforcement, task drift scoring, and stable scope findings. Task failure baselines classify new, existing, and fixed failures from explicit JSON results without running or repairing tests.

The shared `architecture-review` and `change-scope-review` Playbooks have matching thin Codex and Claude Code adapters. The scope advisor stops on reported RG008 errors and pauses for user confirmation on warnings or medium/high drift. Agents do not read contracts directly, recalculate deterministic decisions, create waivers, or modify source code on report authority alone.

Existing repositories remain compatible because architecture contracts, architecture baselines, Task Contracts, and task failure baselines are opt-in. Upgrade by installing the verified v1.4 release and explicitly updating the repository's locked engine identity. No migration may infer contract paths, rewrite repository files, access the network from hooks, or weaken existing RG001-RG006 enforcement.

The v1.4 source catalog restores the verified v1.2.0 and v1.3.0 history before appending v1.4.0, so signed upgrade advice retains the complete stable release chain.
