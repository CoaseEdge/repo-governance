# v1.5 release

Version 1.5 adds deterministic proportional-engineering governance without changing repository configuration schema version 1, pre-push protocol version 1, or execution-contract version 1. Task Contract version 2 is additive, and version 1 contracts remain fully supported without automatic migration.

RG009 measures Git diff facts only: new files, added lines, test files, test added lines, and explicitly mapped change categories. Repository mappings assign one effective category by declaration order, and Task Contract version 2 authorizes the categories and budgets available to the task. Exact content-preserving renames do not consume new-file or added-line budgets. RG008 keeps its existing path-scope responsibility.

Engineering profiles have the fixed order `small < standard < high < critical`. Explicit path-based risk zones may raise, but never lower, the requested profile. Check and PR reports expose deterministic verification advice plus `satisfied`, `needs-confirmation`, or `blocked` governance decisions; they never claim that the user objective is complete.

RG001 requirements may select `change`, `execution`, or `either` evidence. Omitted modes retain the previous `change` behavior. Local PASS receipts are same-workspace caches bound to the current diff and declared command identity. Clean-checkout verification derives same-session evidence only from test entries reached by the governed execution profile, then performs the final governance check without creating portable receipts or a new integrity protocol.

The engine performs no semantic code analysis, LLM judging, inferred category or risk classification, telemetry, or new network access. Existing repositories remain compatible and must explicitly install the verified v1.5 release before updating their locked engine identity.
